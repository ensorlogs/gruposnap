# Aviso legal y alcance del repositorio

Este repositorio publica **únicamente** el tema hijo WordPress `gruposnap`: ajustes y capa de mantenimiento desarrollados por **EnsorLogs** para un **proyecto cliente**.

## Tema padre (terceros)

El sitio del cliente utiliza un **tema comercial de terceros** adquirido bajo licencia privada. Ese tema **no forma parte de este repositorio**, no se redistribuye aquí y está protegido por el copyright de su autor.

La línea `Template:` en `style.css` solo indica el slug técnico que WordPress exige para enlazar el tema hijo con el padre ya instalado en el servidor.

## Uso del código publicado

- Pensado para **portfolio** y entrega controlada al cliente (releases).
- **No** es un tema reutilizable ni una alternativa al producto comercial del padre.
- No incluye plugins, medios, base de datos ni configuración del servidor.
