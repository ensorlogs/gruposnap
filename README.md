# GrupoSnap

**Proyecto cliente** — capa de personalización (tema hijo WordPress) y entregas por **GitHub Releases**.

Repositorio de **portfolio** (EnsorLogs): documenta el flujo de mantenimiento sin publicar el sitio en producción, credenciales, rutas locales ni el tema comercial del que depende el hijo.

## Qué hay aquí (y qué no)

| Sí | No |
|----|-----|
| Código propio del tema hijo `gruposnap` | Tema padre comercial (licencia de terceros, instalado aparte) |
| Automatización `gruposnap.zip` por tag | WordPress core, plugins, uploads, BBDD, `wp-config` |
| Comprobación de actualizaciones en WP | Código reutilizable del producto comprado a terceros |

Detalle legal: [COPYRIGHT.md](COPYRIGHT.md).

## Releases

Tag `vX.Y.Z` → GitHub Actions → asset `gruposnap.zip` → actualización en el WordPress del cliente.
